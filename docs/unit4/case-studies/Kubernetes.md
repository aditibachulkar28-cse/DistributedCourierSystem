# Kubernetes Case Study

Kubernetes orchestrates containers across a cluster. The control plane stores desired state and schedules workloads; worker nodes run Pods. It can scale replicas and replace failed containers, which makes it a distributed control system.

Benefits are portability, scaling and self-healing. Limitations are operational complexity and resource overhead. Viva: **What is a Pod?** Kubernetes' smallest deployable unit, containing one or more containers.
