# Cloudflare Case Study

Cloudflare operates a distributed edge network. Its edge locations can provide CDN caching, DNS, traffic filtering and application services close to users. Requests can be routed to nearby healthy locations, reducing latency and improving resilience.

It illustrates CDN, load distribution and fault tolerance. A limitation is that configuration mistakes or outages can affect traffic broadly. Viva: **What is a CDN?** A network that serves cached content from locations near users.
