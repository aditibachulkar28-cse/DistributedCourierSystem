# Megaport Case Study

Megaport provides software-defined connectivity between data centres and cloud providers. It demonstrates distributed networking because customers connect geographically separate systems through programmable network services. A company can create a private link from its data centre to a cloud region.

Benefits include flexible provisioning and private connectivity. Availability depends on physical locations, provider coverage and service design. Viva: **Why is it relevant?** It connects distributed cloud and data-centre workloads.
