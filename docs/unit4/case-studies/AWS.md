# AWS Case Study

AWS is a cloud platform with globally distributed Regions and Availability Zones. Services such as EC2, S3, RDS and Lambda let applications distribute compute, storage and databases. Deploying replicas across Availability Zones improves resilience.

Advantages are elasticity and broad managed services; limitations include cost management, complexity and vendor dependence. Viva: **What is an Availability Zone?** An isolated location within an AWS Region used to improve availability.
